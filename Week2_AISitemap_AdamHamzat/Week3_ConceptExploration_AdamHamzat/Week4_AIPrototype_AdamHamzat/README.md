## Tool used
Claude (AI assistant) connected to Figma, used to build the interactive prototype. I wrote the prompts and reviewed the results.

## Real behaviors in the prototype
- Add to cart changes the button into a quantity stepper and updates the cart badge
- Cart shows totals, a free-delivery progress bar, and a checkout that leads to an order confirmation
- Sort by: Relevance, Price (low to high), Highest rated reorders the products
- Tapping a product opens its details screen with Add to cart and Buy now

## Prompts used
1. First prompt (front-loaded): Turn my ShopHive Home screen (Concept A: clean, search-first, green) into a working mobile prototype with search, category chips, add to cart, a cart with totals and a free-delivery progress bar, a wishlist, a checkout success screen, and a flash-sale timer. Use Nigerian sample products and Naira prices.
2. Follow-up 1: Add a Sort by option: price low to high and highest rated.
3. Follow-up 2: Add a product details screen when I tap a product.
