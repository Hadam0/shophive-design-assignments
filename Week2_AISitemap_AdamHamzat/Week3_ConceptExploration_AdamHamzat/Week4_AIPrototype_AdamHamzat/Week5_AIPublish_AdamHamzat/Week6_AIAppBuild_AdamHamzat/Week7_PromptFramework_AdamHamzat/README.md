# Week 7: Prompt Framework (Before and After)
**Name:** Adam Hamzat
**Task I redid:** Week 3 concept exploration (ShopHive Home screen directions)
**Tool used:** Claude AI connected to Figma for both runs
## The two prompts
- **Before (rough):** the original assignment text: generate 3+ concept directions for one core screen and pick a favourite. No brand, audience, content list or constraints.
- **After (structured):** a prompt with Task, Context, Elements, Behavior and Constraints. It asks for 4 directions with different layout strategies, names the Nigerian shopper context and the ShopHive brand, lists what every screen must include, and sets 44px tap targets, AA contrast and a maximum of 4 products per screen.

## What improved
- Brand fit: all four new concepts use the ShopHive green and Inter; two of the three Week 3 concepts did not.
- Trust cues: every new concept has one; only one Week 3 concept did.
- Distinct directions: 4 different layout strategies instead of 3 colour themes.
- Decision support: a scorecard on 5 criteria with trust weighted double. It recommended the trust-led Concept C (26 vs 24 for Concept A).
- Fixes needed after the first run: none, compared with several in Week 3.

## Limits
Both runs used the same AI. The before run happened earlier in the same conversation, so it could draw on earlier context. Scores are my own judgement, not measured results.
