# 11: Developer Handoff

**Name:** Adam Hamzat
**Dev Mode link:** https://www.figma.com/design/UwaeIAxZWKL9vcxBfsEGLA/FLEXISAF?node-id=2305-787&m=dev

## What is handed off
The ShopHive buyer purchase flow, 7 screens: Welcome, Sign Up, Home, Product details, Cart, Checkout and Order placed. The screens are marked Ready for dev and linked as a prototype starting at Welcome.

## Tool used
Claude AI

## How everything ties to the design system
- Every colour, font, spacing value and corner radius is a variable or text style from my 9-10 design system.
- Checked layer by layer: 185 of 185 fills, 129 of 129 strokes, 119 of 119 text styles, 156 of 156 paddings, 66 of 66 gaps and 71 of 71 corner radii are bound to tokens.
- Every control is an instance of a design system component (Button, Text Field, Checkbox, Search Bar, Chip, Product Card, Navigation Item, Avatar, Alert, Quantity Stepper, Progress Bar, Radio).

## What developers will find in Dev Mode
- Variable and style names in the Inspect panel
- Component names and properties
- Developer annotations on key fields (password rules, product grid, free-delivery progress, pay button)
- A README frame with inspect steps, behaviour and validation notes per screen, and the tokens as ready-to-copy CSS (Light and Dark)
- Export settings: screens as PNG @2x, logo as SVG
