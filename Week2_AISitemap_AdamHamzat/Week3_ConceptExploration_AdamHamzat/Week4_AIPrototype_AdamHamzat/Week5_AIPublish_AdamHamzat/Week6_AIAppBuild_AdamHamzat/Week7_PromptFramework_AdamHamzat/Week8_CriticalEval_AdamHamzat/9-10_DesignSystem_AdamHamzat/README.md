**Name:** Adam Hamzat
**Figma library link:** https://www.figma.com/design/UwaeIAxZWKL9vcxBfsEGLA/FLEXISAF?node-id=2252-842&t=f6yyyPOsIBcCsRQ7-1

## Tool used
Claude AI

## What is in the design system
- Cover with design principles and an explanation of how the tokens are organised
- Foundations: primitive colours, 27 semantic colour tokens with Light and Dark values, type scale, spacing scale (4px base), corner radius and elevation styles
- 17 components, each shown in all of its states: Button, Text Field, Search Bar, Select, Checkbox, Radio, Switch, Chip, Badge, Alert, Toast, Quantity Stepper, Product Card, Navigation Item, Avatar, Progress Bar and Dialog (112 variants in total)
- A notes block on every component: states, tokens used, usage rules and how it adapts across platforms
- Platforms and responsiveness: breakpoints, an iOS / Android / mobile web / desktop web matrix, and live examples built from the components (mobile and desktop buttons, bottom and top navigation, a 2, 3 and 4 column product grid)
- A Light and Dark mode demo using the same components

## Tokens
- Primitives (Colors collection) feed semantic tokens (Theme collection with Light and Dark modes)
- Components use only semantic tokens, so switching a frame to Dark mode restyles everything
- Spacing and radius use the Spacing & Radius collection; elevation uses three shadow styles
